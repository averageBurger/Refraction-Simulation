# Refraction-Simulation

Simple Python script to simulate light refracting through a lense.

Edit variables at the top of the script to change settings.
- convex: True for a convex lense, False for a concave lense.
- topDegree: changes the shape of the lense by the angle that would lie where the two curves join.
- drawNormal: True to draw dotted normal lines where the light hits the lense, False to not.
- parallelLights:True will draw parallel rays of light, False will draw rays of light at different angles all coming from the same point.
- n1: refractive index of the outer material
- n2: refractive index of the lense
